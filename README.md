# Insurance and the Weak Law of Large Numbers

Interactive classroom demo for ECE 3077 micro-teaching (Jiayu Shi, Tianyu Wu).

Example: each customer pays a 300 yuan premium; with probability 1% the insurer pays a 20,000 yuan claim, so net profit per customer is +300 (p = 0.99) or -19,700 (p = 0.01), with mean 100 and variance 3,960,000.

Pick the number of customers n and the deviation epsilon to see the exact probability P(|mean profit - 100| >= epsilon) and the Chebyshev bound sigma^2/(n epsilon^2).
